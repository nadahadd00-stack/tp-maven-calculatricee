# TP Maven Calculatrice

Projet Maven simple réalisé avec Java et IntelliJ IDEA.

## Description
Cette application implémente une calculatrice simple avec les opérations de base :
- addition
- soustraction
- multiplication
- division

## Structure du projet
- `src/main/java` : contient le code principal
- `src/test/java` : contient les tests unitaires
- `pom.xml` : fichier de configuration Maven

## Technologies utilisées
- Java
- Maven
- JUnit
- IntelliJ IDEA

## Fonctionnalités
- Ajouter des méthodes de calcul dans la classe `Calculatrice`
- Exécuter la classe principale `Main`
- Tester les méthodes avec JUnit

## Commandes Maven utilisées
```bash
mvn compile
mvn test
mvn package
## Résultat
Le projet compile correctement et tous les tests passent avec succès.
